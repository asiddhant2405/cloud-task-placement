Problem Formulation

Given a set of servers $V = \{S_1, \dots, S_m\}$ with capacities $C_j$, a network latency matrix $D[u][v]$, and a set of tasks $T = \{t_1, \dots, t_n\}$ where each task $t_i$ has a CPU demand $c_i$, request traffic volume $\lambda_i$, and an anchor server $a_i$ where user queries originate.

$$\min_{x} \quad \frac{\sum_{i=1}^n \lambda_i \cdot D[a_i][x_i]}{\sum_{i=1}^n \lambda_i} \quad \text{subject to} \quad \sum_{i: x_i = j} c_i \le C_j \quad \forall j \in \{1,\dots,m\}$$

Where $x_i \in \{1,\dots,m\}$ denotes the chosen host server for task $t_i$.

Dynamic Programming State Formulation

Let $dp[j][S]$ be the minimum latency cost incurred by assigning subset of tasks $S \subseteq \{1,\dots,n\}$ across the first $j$ servers:

$$dp[j+1][S \cup A] = \min \left\{ dp[j+1][S \cup A], \; dp[j][S] + \text{cost}_j(A) \right\}$$

Where $A \subseteq (\text{full} \setminus S)$ is any valid subset of remaining tasks whose combined CPU demand fits server $j$ ($\sum_{t \in A} c_t \le C_j$), and $\text{cost}_j(A) = \sum_{t \in A} \lambda_t \cdot D[a_t][j]$.

By enumerating submasks using the classic bitwise trick A = (A - 1) & rest, the total state transitions across all subsets take exactly $\sum_{k=0}^n \binom{n}{k} 2^{n-k} = 3^n$, resulting in an exact global optimum in $O(3^n \cdot m)$ time.
